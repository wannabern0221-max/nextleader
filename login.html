관계자 로그인

이메일 인증과 관리자 승인을 완료한 정책국 구성원을 위한 내부 서비스 입구입니다.

연결정보 입력 필요
assets/supabase-config.js 파일에 Project URL과 Publishable key를 입력해야 합니다.
내부 포털
비밀번호는 Supabase Auth에서 안전하게 처리되며 홈페이지 DB에 평문으로 저장하지 않습니다.
신청자가 직책이나 시스템 권한을 선택할 수 없습니다. 학교와 기수 그리고 이름과 부서를 확인한 뒤 국장 또는 수석부장이 승인합니다.
SIGN-UP PROCESS

관계자 가입 절차

공개 페이지는 누구나 열람할 수 있으며 내부 기능만 승인을 요구합니다.

  1. 학교와 기수 그리고 이름과 부서 입력
  2. 가입한 이메일에서 인증 버튼 클릭
  3. 국장 또는 수석부장이 신청 정보 확인
  4. 승인 완료 후 내부 포털 이용
