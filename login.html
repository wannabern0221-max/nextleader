이메일 인증과 관리자 승인을 완료한 정책국 리더를 위한 내부 서비스 입구입니다.

서비스 연결 설정 필요
현재 리더 서비스 연결 설정이 완료되지 않았습니다. 홈페이지 관리자에게 문의해 주세요.
·

보안을 위해 30분 동안 활동이 없으면 자동으로 로그아웃됩니다.

비밀번호는 안전한 인증 시스템에서 암호화하여 처리하며 홈페이지에 원문으로 저장하지 않습니다.
현재 맡고 있는 직책을 입력해 주세요. 신청 직책은 승인 화면에 참고 정보로 표시되며 승인 전에는 어떠한 관리 권한도 부여되지 않습니다. 정책국장 또는 해당 부서 수석부장이 확인하면서 실제 직책을 확정합니다.
ACCOUNT HELP

계정 지원

@
로그인 아이디는 가입한 이메일 주소입니다.

이메일이 기억나지 않으면 정책국 관리자에게 이름과 학교 그리고 기수를 알려 확인을 요청해 주세요.

관리자는 로그인 이메일만 확인할 수 있으며 비밀번호는 확인할 수 없습니다.
입력한 이메일로 새 비밀번호 설정 링크를 전송합니다.
SIGN-UP PROCESS

리더 가입 절차

공개 페이지는 누구나 열람할 수 있으며 내부 기능만 승인을 요구합니다.

  1. 학교와 기수 그리고 이름과 소속·현재 직책 입력
  2. 가입한 이메일에서 인증 버튼 클릭
  3. 정책국장 또는 해당 부서 수석부장이 신청 정보 확인
  4. 승인 완료 후 리더 홈 이용
