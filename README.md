# 대한간호학생회 부산 정책국 홈페이지 준최종본

## 포함된 화면
- 메인 홈페이지
- 정책국 소개
- 공지사항
- 카드뉴스
- 정책 콘텐츠
- 주요 일정
- 관계자 회원가입 신청 미리보기
- 공지 팝업 및 오늘 하루 보지 않기
- 모바일 반응형 메뉴

## 현재 단계
이 버전은 GitHub Pages에서 바로 열 수 있는 정적 초안입니다.
게시글 작성, 실제 회원가입 승인, 파일 업로드, 관리자 권한은 아직 연결하지 않았습니다.
Supabase 연동 단계에서 구현합니다.

## GitHub Pages에 올리는 방법
1. 새 GitHub 저장소를 만듭니다.
2. 압축을 푼 뒤 폴더 안의 파일을 저장소 최상단에 업로드합니다.
3. GitHub 저장소의 Settings → Pages로 이동합니다.
4. Source에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, Folder는 `/(root)`를 선택하고 저장합니다.
6. 배포가 끝나면 GitHub Pages 주소로 접속합니다.

## 수정 위치
- 메인 문구: `index.html`
- 전체 색상과 디자인: `assets/style.css`
- 팝업과 메뉴 동작: `assets/app.js`
- 홈페이지 표시용 엠블럼: `assets/emblem.png`
- 원본 제공 로고 보관: `assets/logo-original.png`

## 주의
예시 게시물과 일정은 실제 운영자료가 아닙니다.


## 로고 관련
제공된 원본 로고에는 이전 명칭이 들어 있어 현재 준최종본에서는 중앙 엠블럼만 추출해 사용했습니다.
새 명칭이 반영된 공식 로고를 받으면 `assets/emblem.png`만 교체하거나 전체 로고형으로 다시 조정할 수 있습니다.
